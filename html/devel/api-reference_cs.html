API Reference

K rozhraní REST API služby SouDeC lze přistupovat přímo z těchto stránek nebo pomocí webových programových nástrojů, které podporují standardní metody požadavků HTTP a formát JSON pro zpracování výsledků.

Požadavek API Popis Metoda HTTP
detect detekuje a klasifikuje zdroje GET/POST
info vrátí verzi serveru a seznam podporovaných vlastností GET/POST

Metoda detect

Zpracuje vstupní data tak, jak je popsáno v uživatelské dokumentaci.

ParametrPovinnýTyp datPopis
textanořetězecVstupní text v kódování UTF-8.
inputneřetězecVstupní formát; možné hodnoty: txt (defaultní), presegmented (věta na řádek), viz. vstupní formát.
outputneřetězecVýstupní formát; možné hodnoty: txt (defaultní), html, conllu, viz. výstupní formát.
statsneřetězecFormát statistik; možné hodnoty: html (defaultní), tsv (hodnoty oddělené tabulátorem), nebo čárkou dělený seznam těchto možností.
uilangneřetězecJazyková lokalizace vrácených informací; možné hodnoty: en (defaultní), cs.

Odpověď serveru je ve formátu JSON s touto strukturou:

{
 "message": "přehledová_zpráva"
 "result": "zpracovaný_výstup"
 "stats_html": "statistiky_html" (pokud byl tento formát požadován parametrem stats či defaultně)
 "stats_tsv": "statistiky_tsv" (pokud byl tento formát požadován parametrem stats)
}

přehledová_zpráva je krátká přehledová zpráva o aktuálním volání REST API,
zpracovaný_výstup je výstup programu SouDeC ve zvoleném výstupním formátu,
statistiky_html je přehled ve formátu HTML obsahující detekované zdroje a jejich třídy,
statistiky_tsv je přehled ve formátu TSV (hodnoty oddělené tabulátorem) obsahující detekované zdroje a jejich třídy.

Metoda info

Vrátí informace o serveru - verzi služby SouDeC a seznam podporovaných vlastností.

ParametrPovinnýTyp datPopis
uilangneřetězecJazyková lokalizace vrácených informací; možné hodnoty: en (defaultní), cs.

Odpověď je ve formátu JSON s touto strukturou:

{
 "version": "verze_SouDCu"
 "features": "podporované_vlastnosti"
}

verze_SouDCu je verze serveru sestávající z čísla verze a data vytvoření této verze.
podporované_vlastnostijsou seznam podporovaných vlastností.

Příklad pro webový prohlížeč

http://quest.ms.mff.cuni.cz/soudec/api/detect?input=txt&output=txt&text=SouDec tvrdí, že tohle je citace.

Přístup k API pomocí Curl

Popsané rozhraní REST API lze snadno používat pomocí curl. Několik příkladů:

Předání vstupu z příkazové řádky (předpokládá se nastavení prostředí UTF-8)

curl --data 'input=txt&output=txt&text=SouDec tvrdí, že tohle je citace.' http://quest.ms.mff.cuni.cz/soudec/api/detect

Použití vstupního souboru (soubory musejí být kódovány v UTF-8)

curl --data-urlencode 'input=txt' --data-urlencode 'output=html' --data-urlencode 'text@input_file.txt' http://quest.ms.mff.cuni.cz/soudec/api/detect

Konverze výsledku z formátu JSON do prostého textu

curl --data 'input=txt&output=txt&text=SouDec tvrdí, že tohle je citace.' http://quest.ms.mff.cuni.cz/soudec/api/detect | PYTHONIOENCODING=utf-8 python -c "import sys,json; sys.stdout.write(json.load(sys.stdin)['result'])"
