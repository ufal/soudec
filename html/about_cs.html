SouDeC (Source Detection and Classification) je program, webová aplikace a služba REST API pro detekci a klasifikaci citačních zdrojů v českých textech. Vstupní text je zpracován pomocí externích služeb pro větný rozbor (UDPipe) a rozpoznání jmenných entit (NameTag). Program poté v textu identifikuje citační zdroje a klasifikuje je do jedné z pěti tříd: anonymous, anonymous-partial, unofficial, official-non-political, official-political.
